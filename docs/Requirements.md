# Use Cases

## POC/MVP

I have a very specific use case to get started. I am a member of the architecture committee for one of my HOAs. There are always a number of projects in various stages. The projects could be new construction, renovation, etc. We have published guidelines that specify the types of projects, the fees, the approvals needed, etc. I want a way to:

- Keep track of all the projects
  - The type of project
  - The project status
  - All the project contacts (owners, designers, contractors, etc.)
  - A history of the project when requests were submitted, when approved, denied, committee notes, etc.
  - Deposits paid and refunded
  - Track all the documents related to the project: plans, surveys, etc.
- See all the projects associated with a unit
