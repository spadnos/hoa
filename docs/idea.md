## Problem

I am a member of a homeowners associations. The HoA has rules for when homeowners want to build new houses on their lots, make renovations, repairs, etc. The HoA needs to track all of these projects. Depending on the project type, fees, reviews of plans, etc may be required. I want to create a simple file based system that will allow me to track these projects. Each project should be a separate directory. Each project may contain plans and other documents that are specific to the project. Each project should also have a file that tracks the status of the project. I would also add documents like the Architectural Guidelines that are not project specific. These can live in the parent directory. The Guidelines define the different types of projects, what approvals are needed, what fees are required, etc.
